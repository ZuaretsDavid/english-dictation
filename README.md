# English Dictation – תרגול הכתבה באנגלית

משחק לתרגול מילים להכתבה: כרטיסיות, הכתבה, חידון, זיכרון, כתיבה וציור, אותיות מבולבלות והאות החסרה.

## הוספת הכתבה חדשה
1. נכנסים לתיקייה `lists`, לוחצים **Add file** ואז **Create new file**.
2. שם הקובץ הוא התאריך, למשל `2026-11-24.txt`.
3. כל שורה היא מילה באנגלית, מקף, ואז התרגום:
   ```
   # הכתבה 24.11.2026
   apple - תפוח
   house - בית
   ```
4. לוחצים **Commit changes**. אחרי דקה בערך הרשימה מופיעה במשחק, והיא נבחרת אוטומטית כי היא החדשה ביותר.
