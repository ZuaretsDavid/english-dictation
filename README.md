# unbox your English · לצאת מהקופסה עם יראת זוארץ

אתר לתרגול אנגלית לילדים, עם שלושה חלקים:
- **הכתבה** (`dictation.html`): כרטיסיות, הכתבה, חידון, זיכרון, כתיבה וציור, אותיות מבולבלות והאות החסרה.
- **סיפורים** (`stories/`): סיפורים קצרים עם הקראה, תרגום לכל מילה ומשחק התאמה. אפשר גם **לצלם דף מהספר** (`stories/photo.html`), והאתר בונה ממנו סיפור.
- **הכנה למבחן** (`tests.html`): בוחרים את תאריך המבחן. לכל נושא יש הסבר ותרגול, ויש גם מבחן ניסיון עם ציון וקישורים לתרגול מהמורה.

## הוספת הכתבה חדשה
1. נכנסים לתיקייה `lists`, לוחצים **Add file** ואז **Create new file**.
2. שם הקובץ הוא התאריך, למשל `2026-11-24.txt`.
3. כל שורה היא מילה באנגלית, מקף, ואז התרגום:
   ```
   # הכתבה 24.11.2026
   apple - תפוח
   house - בית
   ```
4. לוחצים **Commit changes**. אחרי דקה בערך הרשימה מופיעה במשחק, והיא נבחרת אוטומטית כי היא החדשה ביותר.

## סיפור מצילום
- הזיהוי של הטקסט נעשה בדפדפן עם [Tesseract.js](https://github.com/naptha/tesseract.js), והתרגום דרך Google Translate. אין צורך במפתח או בהרשמה.
- הסיפורים שמצלמים נשמרים רק במכשיר שבו צילמו אותם, ולא עולים לשום מקום.
- צילום ישר, באור טוב ובלי סימונים בעיפרון נותן את התוצאה הכי טובה. לפני שהסיפור נבנה אפשר לתקן את הטקסט.
